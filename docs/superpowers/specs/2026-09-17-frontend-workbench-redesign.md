# VidVeya 前端流线型工作台与多任务体验重构设计规格书

- **日期**：2026-09-17
- **版本**：v0.1.8+
- **状态**：已批准 (Approved)

---

## 1. 背景与业务目标

VidVeya 是一款专为 Windows 平台打造的高性能 YouTube & Shorts 本地视频下载器，具备源格式音视频智能组合、无损合并与完整性校验能力。
随着引入了 **多任务并发调度**、**自适应退避重试**、**桌面通知** 与 **完成音效**，原有的 UI/UX 架构面临以下痛点：
1. **页面拓扑割裂**：原来“新建下载”、“下载任务”、“下载记录”分为 3 个独立导航页面，用户在添加任务后频繁在“任务”与“记录”间跳页；
2. **操作链条冗长**：新建下载需经历“复制 -> 粘贴 -> 点击解析 -> 等待 -> 点击下载 -> 弹框询问跳转”，缺乏剪贴板智能嗅探与自动触发；
3. **任务信息呈现密集且杂乱**：任务卡片标题被横向排布的 4 个按钮挤压严重，重试状态缺乏直观的倒计时感知；
4. **设置项组织松散**：新增的并发任务数、自动重试上限、桌面通知与提示音缺少清晰的逻辑分组。

**重构目标**：
- 打造现代 Windows 11 Fluent 风格的“流线型工作台”；
- 缩减无意义点击与页面跳转，实现“一键粘贴即解析”、“加入队列原地平滑反馈”；
- 统一任务状态与历史归档，提供沉浸清晰的传输管理体验。

## 2. 整体信息架构设计 (Information Architecture)

### 2.1 导航结构收敛（4 页收敛为 3 大工作区）

```
VidVeya 桌面客户端
├── 1. [↓ 新建下载] (New Download)
│      ├── 智能剪贴板嗅探与 Hero 链接胶囊
│      ├── 视频媒体信息卡片 (缩略图/标题/时长/作者)
│      ├── 动态清晰度芯片矩阵 (4K/1080P/720P/音频，预估体积与帧率)
│      └── 原地任务提交与动效反馈
│
├── 2. [⇋ 传输列表] (Transfers Workbench)
│      ├── 顶部分段控制器 [进行中 (Active)] | [已完成 (History)]
│      ├── 批处理控制组 (全部暂停/全部继续、清空已完成)
│      ├── 关键词实时过滤检索栏 (秒级过滤标题与格式)
│      ├── 活跃任务卡片队列 (TaskCard: 速度/ETA/进度条/重试倒计时)
│      └── 已完成历史数据表格 (一键播放、文件夹定位、格式微标)
│
└── 3. [⚙ 偏好设置] (Settings)
       ├── 卡片 1: 外观与偏好 (界面主题、界面语言、关闭窗口行为)
       ├── 卡片 2: 下载与调度 (最大并发 1~5、自动重试 0~10、桌面通知、完成音效)
       ├── 卡片 3: 存储与网络 (下载目标目录、可选 HTTP/SOCKS 代理)
       └── 卡片 4: 凭证与账号 (YouTube 登录态 Cookie 导入与保险库状态)
```

### 2.2 侧边栏常驻微型状态面板 (Sidebar Mini Status Panel)
- **实时汇总展示**：在侧边栏底部常驻展示“传输摘要”，包含：
  - 总下载速度：如 `⚡ 12.4 MB/s`
  - 队列概况：如 `2 个任务下载中 · 1 个排队`
  - 总体进度指示条
- **快捷交互**：点击微型状态面板直接平滑切换至【传输列表】页面。

## 3. 详细页面交互与组件规范

### 3.1 【新建下载】页设计规范

#### 1. 剪贴板智能检测 (Smart Clipboard Sniffing)
- **触发时机**：应用窗口激活或用户点击链接输入框时；
- **判断逻辑**：若剪贴板内包含符合 `youtube.com` 或 `youtu.be` 的有效链接，且当前输入框为空或为不同链接；
- **交互形式**：在 Hero 输入框内自动填入，并在框内右侧显示“已识别剪贴板链接”微型气泡提示，避免侵入式弹窗打扰。

#### 2. 粘贴即解析 (Paste & Go)
- 用户手动按 `Ctrl+V` 或点击输入框右侧的“粘贴”按钮后，若内容通过合法性校验，直接启动 `analyze()`，无需用户多点一次“解析视频”。

#### 3. 链接输入胶囊 (HeroInput)
- **布局**：
  - 左侧：精美链接图标 🔗；
  - 中间：全宽自适应单行输入框，内置“✕”一键清除按钮；
  - 右侧：统一主操作按钮。未输入时显示“粘贴并解析”；输入有效链接后自动转化为“解析中…”（带微型旋转或动态文字指示）；解析成功后变为“重新解析”。

#### 4. 空状态与媒体信息卡片
- **空状态**：展示简洁的居中微视觉插画与引导提示：“复制 YouTube 视频或 Shorts 链接，在此处开始下载”，移除原先占位突兀的大灰色卡片；
- **解析就绪卡片**：
  - 视频封面图（160×90，16:9 圆角微缩图，支持高分屏自适应）；
  - 视频主标题（最多 2 行，悬停显示全称气泡）；
  - 副信息栏（频道作者、视频发布日期、视频时长）；
- **画质芯片矩阵 (Quality Chips Grid)**：
  - 废弃原来生硬的“快速下载”与“高清下载”模式分离；
  - 自动将所有可选流按分辨率升序排列为精致卡片芯片；
  - 芯片内标明：清晰度（如 `1080P`）、视频格式（如 `MP4 · H.264`）、帧率（如 `60 fps`）、预估体积（如 `128.4 MB`）；
  - 默认自动高亮选中最高画质（兼顾兼容性与清晰度的最佳选项）；
- **主操作与原地反馈**：
  - 底部操作栏展示当前默认下载文件夹（附带“修改”快捷文字链接）；
  - 主按钮为醒目的“立即加入下载队列”；
  - 点击后：按钮展示平滑的微动效（“已添加至传输列表 ✓”），并在输入框下方淡入轻量状态横幅，提供“查看任务列表 ➔”快捷入口与“继续添加下一条”按钮。

### 3.2 【传输列表】双模态流线设计规范

#### 1. 顶部控制栏 (Toolbar)
- **分段切换器 (Segmented Switch)**：
  - `[ 进行中 (Active Count) ]` 与 `[ 已完成 (Completed Count) ]`，两态一键切换，当前选中项高亮；
- **批量操作区**：
  - 处于【进行中】视图时：显示 `全部暂停` / `全部继续`、`全部取消`；
  - 处于【已完成】视图时：显示 `清空已完成记录`（仅清除历史记录，不误删已下载的文件）；
- **检索栏 (Filter Input)**：
  - 支持对进行中任务或已完成历史进行毫秒级实时关键词搜索。

#### 2. 任务卡片深度重构 (TaskCard)
- **信息层级优化**：
  - 第一行：视频主标题（全宽展示，右侧仅放置一个优雅的次级操作菜单或图标组：暂停/恢复、取消 ✕）；
  - 第二行：清晰度标签徽章（如 `1080P MP4 60FPS`）+ 状态文字（如 `下载中 · 8.4 MB/s · 剩余 45 秒`）；
  - 第三行：现代 Fluent 细进度条（8px 高度，带微圆角，根据状态呈现主题色/警告色/绿色）；
  - 第四行（视状态按需呈现）：
    - **合并与校验**：展示 `正在无损合并音频与视频轨…`（带呼吸动态指示）；
    - **重试等待**：展示警告条目 `⚠️ 网络受限 (HTTP 429)，将在 18 秒后自动重试 (第 1/3 次) [立即重试]`；
    - **已完成**：展示 `完成于 14:28:10 · 256.8 MB`，并提供 `播放` 与 `打开所在文件夹` 快捷入口。

#### 3. 历史记录表优化 (History View)
- 继承并优化现有的 `QTableWidget` 体验；
- 包含列：`视频名称`、`清晰度/大小`、`状态`、`完成时间`；
- 支持整行双击默认调起系统播放器播放；
- 鼠标右键唤起上下文菜单（打开文件、打开文件夹、重新下载、删除记录）。

### 3.3 新增功能模块规范

#### 1. 并发调度与智能重试机制 (DownloadManager & Auto-Retry)
- **并发控制**：默认 3 个并发任务，支持在设置中配置为 1~5；活跃任务跑满时，后续任务自动处于 `queued`（排队）状态；
- **自适应退避**：
  - 遇到瞬态网络异常（超时、连接中断），依次等待 10s、30s、60s 后重试；
  - 遇到 HTTP 429（频繁请求），强制等待至少 60s 或按服务器返回的时长退避；
  - 重试等待期间自动释放并发槽位，让队列中的其他任务优先执行；到期后重新加入排队；
  - 重试次数耗尽后，状态置为 `failed`，保留手动一键重试能力。

#### 2. 桌面通知 (Desktop Notification)
- **外观**：基于 `CompletionPopup` 实现轻量无边框悬浮卡片，位于屏幕右下角（避开任务栏）；
- **行为**：
  - 仅在用户开启“下载完成桌面通知”且窗口处于最小化或后台时弹出；
  - 包含下载成功的视频标题、清晰度规格，以及“播放视频”与“打开文件夹”直达按钮；
  - 5 秒后平滑淡出并销毁，用户鼠标悬停时暂停倒计时。

#### 3. 完成提示音 (Completion Sound)
- **行为**：任务经过音视频有效性校验并成功写入磁盘后触发；
- **保护**：1 秒内若有多个任务同时完成，执行节流保护，只响一声，杜绝噪音轰炸；用户可随时在设置中关闭。

#### 4. 设置页重构 (Settings Grouping)
- 4 大卡片对称对齐：
  1. **外观与偏好**：界面主题（系统/浅色/深色）、界面语言（简体中文/English）、关闭窗口时的行为（最小化/退出）、关闭提示开关；
  2. **下载与调度**：同时下载任务数（1~5 下拉框）、自动重试次数（0~10 下拉框）、下载完成桌面通知开关、播放提示音开关；
  3. **存储与网络**：下载保存目录（选择文件夹）、本地代理配置（支持 HTTP/SOCKS 格式校验与提示）；
  4. **登录态与授权**：已导入登录态状态指示（Cookie 状态检测、导入/清除按钮）。

## 4. 技术架构与组件划分

为了避免 `window.py` 过于臃肿（原 1600+ 行），本次重构将界面代码进行清晰的模块化解耦：

| 模块文件 | 职责定位 |
|---------|---------|
| `src/vidveya/ui/window.py` | 主窗口生命周期、侧边栏导航、全局事件与页面路由编排 |
| `src/vidveya/ui/download_page.py` | 【新建下载】页完整视图、Hero 胶囊、视频信息卡片、画质芯片矩阵 |
| `src/vidveya/ui/transfers_page.py` | 【传输列表】页工作台，整合进行中任务队列与已完成历史记录，分段控制器 |
| `src/vidveya/ui/task_list.py` | 任务列表容器 `TaskList` 与重构后的精致任务卡片 `TaskCard` |
| `src/vidveya/ui/notifications.py` | 桌面通知悬浮窗与系统提示音调度 |
| `src/vidveya/ui/settings_page.py` | 【偏好设置】4 大卡片分组视图与即改即存交互 |
| `src/vidveya/ui/style.py` | 全局 Fluent Design 调色板、样式规则、状态徽标与动效 Tokens |

## 5. 质量保障与回归验证计划

1. **功能完整性回归**：
   - 保证原有的所有自动化测试用例（格式解析、流过滤、多任务调度、进程退出清理）全部兼容通过；
2. **新增交互单元测试**：
   - 测试剪贴板识别与粘贴解析事件；
   - 测试传输列表分段控制器切换、批量暂停/恢复功能；
   - 测试设置项（并发数、重试策略、通知开关）的双向持久化；
3. **视觉与跨主题验证**：
   - 验证深色模式与浅色模式下的对比度与控件协调度；
   - 验证 Windows 缩放比例下的文本与边框抗锯齿表现。
