# VidVeya UI/UX 与产品体验全面重构设计规格说明书 (Spec)

- **创建日期**: 2026-09-16
- **设计主题**: 现代流线型一体化工作台（Modern Streamlined Workbench）
- **适用版本**: VidVeya 0.2.0+
- **覆盖模块**: `src/vidveya/ui/window.py`, `src/vidveya/ui/style.py`, `src/vidveya/i18n.py`, `tests/test_ui.py`

---

## 1. 业务目标与设计愿景

### 1.1 业务目标
将 VidVeya 从传统的“参数罗列型”工具界面，重构为具备顶级现代化桌面体验的“流线型视频下载工作台”：
1. **80% 极速流线路径**：从复制粘贴链接到选好清晰度一键下载，操作步骤减少 50%，无任何多余点击；
2. **零技术认知障碍**：摒弃复杂的底层音视频流表格，以可视化的画质卡片（Quality Cards）直观呈现最佳选择；
3. **消除冗余杂乱**：移除所有重复的按钮、说明和多余的表单提交步骤，实现全软件设置项“即改即存（Auto-Save）”；
4. **质感与沉浸感升级**：引入流线型胶囊输入栏、视频 Hero 预览卡片、行内悬停快捷动作条，带来细腻顺滑的交互质感。

---

## 2. 页面详细重构设计

### 2.1 新建下载页 (New Download)

#### A. 流线型输入胶囊 (Hero Input Capsule)
- **视觉布局**：
  - 宽幅圆角卡片容器（`border-radius: 12px`），内部将 URL 输入框、一键清空按钮（当有内容时显示）、一键粘贴按钮与高饱和度“解析视频”主按钮一体化整合；
- **交互流程**：
  - 获得焦点时呈现 Fluent 柔和发光微边框；
  - 支持回车直接触发解析；
  - 粘贴按钮支持直接读取系统剪贴板中的链接并立刻自动触发解析，无需用户先点粘贴再点解析。

#### B. 视频 Hero 预览卡片 (Video Hero Card)
- **视觉布局**：
  - 解析完成后，平滑展开视频主体预览卡片；
  - **左侧**：圆角封面缩略图（16:9 比例），右下角带有高对比度的半透明时长药丸（如 `12:34`）；
  - **右侧**：
    - 第一行：视频大标题（加粗，字号 16px，最多展示 2 行）；
    - 第二行：频道名称 · 访问权限徽章（如“公开视频”或“频道会员专属”绿色/金黄色药丸标签）；
    - 第三行：下载保存目标目录指示。

#### C. 卡片式清晰度选择器 (Quality Selection Cards)
- **交互彻底革新（替代复杂的 QTableWidget）**：
  - 不再让普通用户面对复杂的编码参数（av01/vp9/独立音视频流）；
  - 将可用清晰度提炼为一组横向流式排列的可视化画质卡片：
    - `4K (2160P)`、`2K (1440P)`、`1080P 全高清 (推荐)`、`720P 高清`、`480P 标清`、`仅音频 (MP3/M4A)`；
  - **单个卡片内容**：
    - 顶部：清晰度大字标（如 `1080P`）+ 推荐标签（如有）；
    - 中部：视频格式（如 `MP4 · 60fps`）；
    - 底部：预估文件大小（如 `128.5 MB`）；
  - **选中态**：高亮边框 + 专属强调色微底色；默认自动智能选中推荐的最佳画质（如 1080P 或源片最高画质）。

#### D. 主动作与一体化下载进度 (Unified Action & Progress)
- **下载动作区**：
  - 单一明确的高优先级主按钮：“下载此视频 (1080P)”；
- **下载进度展示（原位平滑过渡）**：
  - 下载启动后，操作栏无缝过渡为沉浸式动态进度条：
    - 顶部：当前阶段（准备中 / 下载中 / 合并中 / 校验中）；
    - 中部：大号实时百分比（`68%`）与平滑圆角进度条；
    - 底部：实时下载速度（`12.4 MB/s`）与预估剩余时间（`剩余 01:25`）；
  - 下载完成时：原位呈现醒目的绿色验证完成徽标，并提供高优先级的双操作按钮：“▶ 立即播放” 与 “📂 打开文件夹”。

### 2.2 下载记录页 (History)

#### A. 顶部工具栏精简与搜索过滤
- **左侧**：`共 {count} 项记录` 的柔和微标；
- **右侧**：
  - **实时搜索框**（`🔍 搜索视频标题...`）：实时响应输入，对表格中的任务标题进行不区分大小写的本地即时过滤，空状态友好；
  - **表头字段排序提示与清空按钮**：保留右侧“清空记录”次级按钮（带安全二次确认）。

#### B. 现代富媒体表格与行内快捷操作
- **表格列重构**：
  - 优化行高为 `44px`，文字居中对齐，背景带交替微底色与悬停动效；
  - “清晰度”列使用轻量圆角药丸微标（`1080P · MP4`）；
  - “状态”列使用带状态指示小圆点的彩色标签（完成为翠绿色、进行中为蓝色呼吸态、失败为暖红色）；
- **行内快捷操作条 (Inline Quick Actions)**：
  - 彻底移除原本位于页面底部的 4 个重复按钮；
  - 鼠标悬停在表格行上时，该行末尾直接浮现两个轻量快捷图标按钮：
    - `▶ 播放`（仅有文件时可用）
    - `📂 打开文件夹`（仅有文件时可用）
  - 右键菜单保留全量操作（播放、打开文件夹、重新下载、复制链接、复制标题、删除）。

---

### 2.3 设置页 (Settings)

#### A. 全局即改即存机制 (Auto-Save by Default)
- **取消手动保存按钮**：
  - 移除页面中间突兀孤立的“保存设置”大按钮；
  - 切换主题、切换语言、选择保存文件夹、修改代理、修改关闭行为、开启登录态，修改后立即通过后台 Store 持久化；
  - 界面右上角或当前卡片右上角显示微小的柔和提示“✓ 设置已自动保存”。

#### B. 三大结构化分类卡片
1. **常规与偏好**：
   - 界面主题（跟随系统 / 浅色模式 / 深色模式）；
   - 界面语言（跟随系统 / 简体中文 / English）；
   - 关闭窗口时的行为（最小化到任务栏 / 退出软件 / 是否弹窗提示）；
2. **存储与网络**：
   - 下载保存位置（当前路径展示 + “选择文件夹”按钮 + 快捷“打开当前目录”按钮）；
   - 网络代理（输入框，失焦或回车自动校验并保存）；
3. **账号与系统诊断**：
   - YouTube 凭据导入（导入 Cookie / 清除 / 帮助链接）；
   - 内置组件健康状态（正常状态下显示为绿色就绪指示器与版本号；发生异常时才提供折叠展开详情与诊断重检）。

## 3. 技术设计与架构规范

### 3.1 兼容性与模块分层
1. **无破坏性变更**：
   - 核心引擎、后台进程（`WorkerThread`, `engine.py`, `formats.py`, `processes.py`）接口完全保持不变；
   - 本地持久化（`Store`）数据库 Schema 完全保持不变；
   - 现有测试依赖的公开属性（如 `url_input`, `download_button`, `history`, `navigation` 等）保持兼容桥接；
2. **QSS 样式系统扩展 (`src/vidveya/ui/style.py`)**：
   - 扩展画质卡片芯片样式（`QWidget#QualityCard`, `QWidget#QualityCard:hover`, `QWidget#QualityCard[selected="true"]`）；
   - 优化现代搜索框与一体化 Hero 输入框样式；
   - 浅色与深色模式色彩 Tokens 严格匹配。

### 3.2 国际化 (i18n) 全量覆盖
- 在 `TRANSLATIONS["zh"]` 与 `TRANSLATIONS["en"]` 中同步补充所有新组件文案（如 `search_placeholder`, `quality_recommended`, `auto_saved_hint`, `copy_clipboard_success` 等）。
