# VidVeya UI/UX 现代重构设计规范 (Design Spec)

**日期**: 2026-09-15

**目标**: 将 VidVeya 从传统的平铺表格工具，升级为具备 Windows 11 Fluent 质感、动线优雅、支持浅色/深色主题的现代桌面视听应用。

---

## 1. 核心设计目标与风格定位

1. **Windows 11 Fluent / 现代拟扁平卡片风**：
   - 采用 12px / 8px 层次分明的圆角、柔和边框线条与悬浮微阴影。
   - 彻底摆脱冰冷的传统数据表格，全面升级为可视化卡片流与组件徽章（Badges / Pills）。
2. **浅色 / 深色（Light / Dark）双主题自由切换**：
   - 浅色模式：柔和高质感 Slate 浅底色 (#F8FAFC)，白色卡片，灵动红色强调。
   - 深色模式：沉浸式深空灰黑 (#0F1117)，高反差媒体卡片，护眼且富有现代视听工作台质感。
   - 允许用户手动切换或跟随系统。
3. **动线清晰的向导式卡片流**：
   - 未解析前：清爽简洁的欢迎态，引导粘贴或输入。
   - 解析完成后：大缩略图卡片展示完整视频元数据（标题、作者、时长、权限标签）。
   - 格式选择：品质徽章化卡片（清晰度、帧率、编码、预计大小），取消生硬切页，默认预选最佳品质。
4. **沉浸式下载进度与全流程状态反馈**：
   - 主界面五阶段步进器（准备 → 下载中 → 无损合并 → 完整性校验 → 完成）。
   - 速度、剩余时间、已下载体积的仪表化呈现。
   - 侧边栏常驻迷你进度指示，切换页面依然一目了然。
   - 完成后一键“打开文件”、“定位文件夹”。
5. **任务记录与设置卡片化**：
   - 下载记录页提供图文卡片流与单项快捷操作（播放、打开目录、重试）。
   - 设置页按分类（存储、网络、凭据、常规、组件）卡片化展示。
